# BoxD Linux
You have stumbled upon BoxD Linux!

# What is it?
BoxD Linux is a new Linux distro featuring a base chain of it's own tools.

# Stuffs

1. BoxD -- A custom init system that is BLAZING fast (in it's current state) (i swear it boots in like half a sec --cyberstar) 
2. NetworkD -- A simple made from scratch network manager that can be tweaked and edited with using "box net help".
3. Box -- A tool that has the usability of systemctl and speed and simpliticy of runit the for the user to control BoxD & NetworkD with.
