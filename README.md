# BoxD Linux
You have stumbled upon BoxD Linux!

# What is it?
BoxD Linux is a new Linux distro featuring a base chain of it's own tools.

# Stuffs

1. BoxD -- A custom init system that is BLAZING fast (in it's current state)
2. NetworkD -- A simple network manager.
3. Box -- A tool for the user to control BoxD & NetworkD with

# What it's got
* Linux 7.3-rc5 -- with a bunch of stuffs
* Neovim
* Nano
* Curl
* Fastfetch
* Busybox
* Probably other stuff I can't think of right now.

# Why should you, the user, choose this distro?
You shouldn't. Goofy-goober.

# Build
* ./build.sh builds the OS.
* ./bootiso.sh creates a bootable iso.
* ./qemu.sh is my preset for qemu to load it.
